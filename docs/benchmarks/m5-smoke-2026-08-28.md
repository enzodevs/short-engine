# M5 hardware smoke — 2026-08-28

Reference machine: MacBook Pro M5, 32 GB, arm64. Fixture: synthetic Portuguese
speech over a 1280×720 test-pattern video, 43.92 seconds.

| Stage | Real adapter | Elapsed |
|---|---|---:|
| Media preparation | FFmpeg 9.0.1 full | 0.60 s |
| Transcription | MLX Whisper large-v3-turbo | 71.28 s including initial model setup |
| Segmentation | AdaptiveDetector + Silero VAD ONNX | 0.71 s |
| Ranking | Gemini 3.1 Flash-Lite, transcript + JPEG frames | 5.17 s |
| Tracking/render | YOLO26n MPS + FFmpeg/libass | 7.47 s |

Validated output: H.264/AAC, 1080×1920, 41.00 seconds. Gemini scored the
synthetic candidate 33.4/100 and explicitly penalized the irrelevant test-pattern
visuals, confirming that visual evidence materially affects ranking.

The first run also exposed and led to fixes for three integration issues:

- Silero/torchaudio 2.11 requiring TorchCodec for simple WAV reads;
- premature cleanup of a temporary Google Gen AI client;
- Ultralytics' lazy `lap` tracking dependency and cwd model download.
